# \[ phonemes \]
> examples and non-vietnamese approximation have been referenced from wikipedia

## non vocal phonemes
| use           | phoneme | system token |
| ------------- | :-----: | :----------: |
| silent stops  | SP      | sil          |
| breaths       | AP      | br           |
| end breaths   | exh     | x            |
| glottal stops | Q       | cl           |
| vocal fry     | vf      | cl           |
