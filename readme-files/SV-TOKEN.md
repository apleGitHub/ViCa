# \[ phonemes \]
> examples and non-vietnamese approximation have been referenced from wikipedia

## non vocal phonemes
| use           | phoneme | system token |
| ------------- | :-----: | ------------ |
| silent stops  | SP      | sil          |
| breaths       | AP      | br           |
| end breaths   | exh     | x            |
| glottal stops | Q       | cl           |
| vocal fry     | vf      | cl           |

## vowel phonemes
> note: `ax` is mainly used for diphthongs, it should only be next to `i`, `eu`, and `u`

| ipa  | phoneme | example                            | non-viet. approximation           |
| ---- | :-----: | ---------------------------------- | --------------------------------- |
| a    | a       | b**a**, m**a**i, c**a**o           | l**a**ugh, m**a**d                |

| e    | e       | v**ề**, c**â**y                    | d**a**y, s**ai**d (monophthongal) |

| i    | i       | kh**i**, tu**y**                   | s**ea**t                          |
